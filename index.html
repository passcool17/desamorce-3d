Une bombe. Six faces. Un chrono.

Niveau

Mode

Manuel

Jeu fictif — aucune vraie bombe n’a été blessée.

Comment jouer

  • Tourner : glisse à gauche/droite (ou ◀ ▶). Basculer : glisse vers le bas pour voir le dessus, vers le haut pour le dessous (ou ▲ ▼).
  • Toucher les éléments de la face visible : fils, vis, touches, leviers, boutons de couleur.
  • Les indices d’un module sont sur une autre face. En mode duo, certains sont seulement dans le manuel.
  • Fils : coupe les fils dont la couleur est celle d’un voyant allumé (face Panneau).
  • Panneau : dévisse les 4 vis dans l’ordre des chiffres du n° de série (face Fils). Le couvercle tombe : 4 symboles.
  • Clavier : traduis les 4 symboles avec la légende (récompense de l’Aiguille), puis OK.
  • Aiguille : guide la bille jusqu’au drapeau, dans le noir, sans toucher un mur.
  • Interrupteurs (dessus) : lève ceux dont la somme des valeurs égale la TENSION (dessous), puis VALIDER.
  • Séquence (dessous) : des couleurs clignotent ; appuie, dans l’ordre, la couleur que donne la table du dessus.
  • Erreur : pénalité de temps et une croix. Toutes les croix : BOUM.
  • Clavier d’ordinateur : flèches pour tourner/basculer (sur l’Aiguille, les flèches bougent la bille ; Maj + flèche pour tourner), M pour le son.
